# October 2026 development diary

## 02/10/2026 — adopt manually installed GeneralsOnline data

The Android launcher previously treated the community data patch as installed only when
its own SharedPreferences and installed-file record had been written. A player who
copied the official GeneralsOnline package into the documented Zero Hour user-data
directory therefore saw "Not installed yet" and the updater could attempt the same
download again.

The launcher now detects the required community patch file at startup and adopts an
existing manual install without inventing a release version or taking ownership of
the player's Maps directory. Manual installs no longer enter the normal datapack
update loop.

The datapack downloader also keeps SHA-256 verification strict but retries once after
an integrity mismatch using a cache-busting manifest request, disabled HTTP caching,
identity content encoding, and an exact-size check. This handles a stale CDN edge
without accepting an unverified archive.

The existing PC checksum fallback remains responsible for manual installs: the
engine can use the signed pc_exe_crc setting when the launcher did not compute a
package-local executable seed.
